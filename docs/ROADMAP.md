# Roadmap

## M0 - Standalone extraction / redesign
- [x] generic .webui project model
- [x] semantic element palette
- [x] free canvas
- [x] drag & drop
- [x] move / resize / rotate
- [x] layers / lock / visibility
- [x] undo / redo
- [x] grid / snap
- [x] inspector
- [x] image loading
- [x] project save/open
- [x] HTML/CSS export
- [x] preview mode

## M1 - Bring over the best editor behavior
- crop mode with direct image panning
- image scale / focal point controls
- color wheel + hex/RGBA entry
- system and custom font catalog
- numeric fields with mouse wheel stepping
- alignment tools
- context menus
- copy / paste
- multi-select
- keyboard nudging
- clean close / dirty-state dialog
- page width and height direct editing
- zoom percentage and reset controls

## M2 - Real responsive web model
- breakpoints
- per-breakpoint overrides
- fixed / percent / fill / hug
- min/max sizes
- anchor rules applied during viewport resize
- flex row / column
- grid container
- flow layout
- margins / padding / gap
- responsive preview strip

## M3 - Pages and navigation
- multiple pages
- page creation / rename / duplicate / delete
- route names
- navigation links via page picker
- header/footer reusable components
- reusable components

## M4 - Better export
- semantic responsive HTML
- CSS variables / design tokens
- accessible labels
- form semantics
- asset optimization
- generated/ vs custom/ separation
- safe re-export into an existing exported project
- optional React exporter

## M5 - Import / roundtrip
- import arbitrary local HTML/CSS into editable elements
- preserve unsupported source as custom blocks
- explicit conflict handling for re-import
